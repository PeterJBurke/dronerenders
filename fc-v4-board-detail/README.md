# V4 board studio detail

November 12, 2026. User requested a dedicated detailed photorealistic board-render page with a ruler and penny, linked from the frame viewer.

The page uses the full-window layout of Peter Burke’s `fc_comparison_render.html`: a collapsible Legend, compact top-right view/theme controls, a 10 / 50 mm grid and in-scene board labels. It opens with both native boards side by side at the same scale. Board selectors provide individual and provisional-stack views, while **Studio renders** opens the detailed images and downloads. URL options `#top`, `#dark` and `#legend` are supported. The old `viewer.html` link remains a compatible entry point.

The studio panel presents three CAD-based Blender Cycles renders: Upper Logic, Lower Power and the provisional main stack. The interactive Three.js scene allows both boards, either individual board or the main stack to rotate freely. Both studio and interactive views use actual V4 source meshes, green PCB substrate appearance (#086b32), a 70 mm metric ruler with 1 mm divisions and a US penny at19.05mm diameter and1.52mm thickness.

These are rendered CAD models, not hardware photographs. Geometry derives from the November6 native V4 stack export at checkpoint`abe43c2`. Component colours are given plausible presentation roughness/metalness; substrate appearance is green as requested. No canonical CAD component placement or routing changes were made. The display substrate is reconstructed from the native outline and drill data to show actual through holes. Native Gerber exports now supply both-face silkscreen, exposed pads, routing appearance and drill locations. Header housings use dark molded-plastic materials and gold contacts matching the selected TSW-108-08-G-T-RA part. Four lower-board top-side power pads are labelled G / BAT+ / ESC+ / G. J20/J21 presentation bodies are reconstructed from Samtec drawings; their native CAD bindings remain missing; library shapes are not manufacturer-certified; native slab thickness differs from fabrication layers. Service board position is undefined and it is omitted. Stack facing gap8.64mm remains provisional.

The Cycles renders use 48 adaptive samples at 1800 × 1200 pixels. Intel Open Image Denoise 2.5.1 performs the final LDR/sRGB noise cleanup in high-quality mode; original unfiltered Cycles images remain in the engineering `realistic-renders/` folder (earlier images remain in `final-renders/`). The finishing script is included as `denoise-render.py`, and its OIDN executable path can be supplied as the third argument.

The engineering recipe, source hashes, source texture and native Blender scene are under`design/V4/mechanical/board-detail-2026-11-12/`. Prepare using the project placement Python environment, then run Blender background with `render-realistic.py` for the detailed surface version. `build-realistic-geometry.py` creates drilled display substrates and drawing-derived connector bodies; `surface-assets/build-textures.py` creates exact-coordinate native artwork. Scripts refuse to overwrite existing final renders; preserve all prior versions in a dated draft before adapting or rerunning. The Blender scene includes the penny image packed into the file.

Penny appearance is reused from the reference drone gallery. Obverse image: United States Mint, via Wikimedia Commons File:2010 cent obverse.png, public-domain US government work. Interactive underside texture: Leopard2A7m, File:Union Shield Cent.jpg, CC BY-SA4.0. Full attribution is in`assets/PENNY-CREDITS.txt`. The Three.js r160 license is included. Viewer assets are local and support offline file viewing.


Interboard connection: Upper J20 **Samtec CLP-110-02-L-D** mates with Lower J21 **FW-10-03-L-D-250-065**: two rows of ten, 1.27 mm (0.050 inch) pitch, nominal facing-board gap 8.64 mm. The socket body and two header spacers follow published dimensions; small contact pockets and tail bends are visual approximations. Sources: [CLP drawing](https://suddendocs.samtec.com/prints/clp-1xx-xx-xxx-d-xx-xx-xx-mkt.pdf), [FW drawing](https://suddendocs.samtec.com/prints/fw-xx-xx-xx-d-xxx-xxx-xx-mkt.pdf). These are presentation models, not replacement CAD library bindings or validated fit models.

Four interboard screw standoffs have **not** been incorporated into V4. The approved 20 × 20 mm grommet mounting belongs to a separate carrier whose geometry remains unfinished; the render does not invent screw holes through the routed boards. Gold exposed-pad finish is an appearance assumption, not a specified fabrication finish. The pin labels come from our PCB artwork, not a copied Matek pinout. Bottom view reveals the underside artwork and socket.
